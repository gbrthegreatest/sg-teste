# Superior Genes — versão reformulada

Landing page reformulada com identidade mais autoral, baseada em três símbolos:
- DNA: identidade e estrutura
- Infinito: evolução contínua
- Coruja: visão estratégica, inteligência e precisão

## Arquivos principais
- `index.html`
- `styles.css`
- `script.js`
- `config.js`
- `assets/` (logos e favicon)

## Antes de publicar
Abra `config.js` e preencha:
- `whatsappNumber`
- `phoneLabel`
- `instagramUrl` (opcional)

## Portfólio
Os links dos três projetos demonstrativos já estão configurados:
- Clima Ideal
- Vento Clima
- Nexo Ar

## Publicação
1. Envie todos os arquivos para a raiz do repositório no GitHub.
2. Mantenha a pasta `assets` no mesmo nível do `index.html`.
3. Aguarde a atualização do GitHub Pages.
